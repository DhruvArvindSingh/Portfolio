## 🚀 Deployment Instructions

### 1. Vercel (Recommended)
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

### 2. Docker
```bash
# Build image
docker build -t portfolio .

# Run container
docker run -p 3000:3000 portfolio
```

### 3. Traditional Hosting
```bash
# Build static files
npm run build

# Start production server
npm start
```
